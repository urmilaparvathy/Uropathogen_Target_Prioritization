# Data Sources

## Organism
Uropathogenic Escherichia coli (UPEC)

## Genome and Annotation
- Source: NCBI RefSeq
- Data type: Protein-coding genes and functional annotations

## Transcriptomic Data
- Source: NCBI GEO
- Data type: RNA-seq expression profiles under infection-relevant conditions

## Protein Interaction Data
- Source: STRING database
